# C4S - Data Science & Machine Learning Labs

A repository containing coursework, lab exercises, projects, and machine learning models.

## Repository Contents

- **`ai-labs/`** – Artificial Intelligence laboratory exercises and notebooks
- **`numpy-labs/`** – NumPy practice tasks and arrays operations
- **`pandas-labs/`** – Pandas data manipulation and analysis
- **`python-labs/`** – Core Python exercises and practice scripts
- **`ml/`** – Machine Learning projects (including student performance prediction web app)
- **`pd/`** – Pandas web app & demonstrations
- **`quiz-1/`** – Quizzes and implementations (e.g., Linear Regression)
- **`week2-day2/`**, **`week3-day1/`**, **`week3-day2/`** – Weekly coursework, datasets, and training scripts
